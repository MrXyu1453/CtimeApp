# 时舟（CtimeApp）

一个把「任务 → 时间块 → 专注 → 复盘」串成一圈的本地优先时间管理 App。

Expo + React Native，Android / iOS / Web 共用一套代码；数据只保存在设备本地（AsyncStorage），不依赖账号、后端或云同步。首次启动需先同意隐私政策，同意前不初始化计时引擎、不申请任何权限。

技术栈：Expo SDK 57 · React Native 0.86 · TypeScript（strict）· Expo Router · Zustand · Reanimated 4。

## 架构

| 层 | 实现 | 职责 |
| --- | --- | --- |
| 页面与路由 | Expo Router | 今日 / 日历 / 任务 / 专注 / 复盘五条主路由与底部标签 |
| 状态与持久化 | Zustand + persist + AsyncStorage | 单一 store（`ctime-store-v1`），任务、时间块、专注记录与设置 |
| 领域逻辑 | `src/lib/schedule.ts`、`use-focus-engine` | 30 分钟粒度排程、区间统计、按绝对结束时间结算专注 |
| 平台能力 | expo-notifications、expo-blur、Reanimated 4 | 本地通知、磨玻璃、UI 线程动画、触感反馈 |
| 合规与文案 | `src/constants/legal.json` | 隐私政策、用户协议、收集清单、SDK 清单的唯一真源 |

设计取舍：

- **本地优先**：没有账号体系和后端，所有数据留在设备；代价是不支持多设备同步。
- **墙钟结算**：专注以绝对结束时间 `endAt` 为唯一真相，全局引擎在任何页面按真实时间结算；切后台、熄屏、杀进程后都不漂秒。
- **单一数据流**：页面只读写 store，排程与统计由纯函数完成，持久化统一在 store 层处理。
- **权限最小化**：首启同意前不初始化计时引擎、不申请通知权限；通知只在第一次开始专注时申请。

## 功能

- **今日**：一天的时间轴，按 30 分钟粒度显示空闲/已排时段，点空隙即可插入时间块。「自动排程」按优先级、截止时间、预计时长，把未排任务贪心填进当天空闲窗口，且不会把今天的排程落在过去的时间点。
- **日历**：月视图「日程地图」。格子底色深浅表示当天计划时长（相对本月最满的一天），底部细条表示实际专注，小圆点表示占比最高的三个分类，右上角数字表示当天到期任务；选中某天后展开计划/专注/完成/到期与时间块明细，页尾汇总本月执行率与有排程天数占比。
- **任务**：标题、备注、分类、优先级、预计时长、截止日期；支持「全部待办 · 今天 · 逾期 · 已完成」筛选，并标记每条任务是否已排入日程。
- **专注**：番茄钟按绝对结束时间倒计时，可提前停止并按实际分钟记为 partial；iOS / Android 发送本地通知。计时页可进入「息屏显示」：纯黑常亮的大字倒计时，每秒只更新文字，轻触退出。
- **复盘**：本周 / 上周 / 本月的专注时长、轮次、计划时长、完成任务与完成率；计划 vs 实际柱状对比、分类时间去向和数据建议。同一页可调整专注/休息时长、计划时段、外观，并进入隐私政策、用户协议、收集清单、SDK 清单或撤回隐私同意。

## 设计

### 视觉

三套配色（`Colors.light` / `Colors.vivid` / `Colors.dark`），每套配套氛围彩底（`Ambient`）与玻璃材质（`Glass`）。两套日间配色不使用紫色：`light` 走钴蓝＋青，`vivid` 走青绿＋海蓝＋落橙，连分类色也换成玫红；紫色只留给「夜航」。

- 所有正文与次要文字在三套配色的卡片白底、页面底色、选中底色上均按 WCAG 校准，正文对比度 ≥ 4.25:1，渐变主卡与主按钮上的白字 ≥ 4.4:1。
- `AmbientBackdrop` 是一层静态渐变（底色 + 三团径向色斑），不随滚动移动，零帧开销。
- 磨玻璃使用 `expo-blur`：每屏只放 1–2 个 `BlurView`（吸顶栏 + 瞬时提示），卡片不做玻璃，避免滚动时反复模糊导致老 Android 掉帧；`intensity` 挂载时固定，不参与动画。
- Android 11 及以下自动退化为半透明材质；Web 端用 CSS `backdrop-filter` 做预览近似。

### 动效

统一使用 Reanimated 4 + worklets，动画跑在 UI 线程，React 不因动画重渲染；位移与缩放只碰 `transform` 和 `opacity`。

- `PressableScale` 是全站统一按压组件：按下 scale 0.97 / 150ms，触控区靠 `hitSlop` 撑到 44pt。
- `Sheet` 底部弹层用原生 Modal 做层级，叠加手指跟随的下滑关闭，按速度与距离判定是否退出。
- `Segmented` 的胶囊用过渡滑动，切换筛选器不引发布局重排。
- `useEnter` 做最多 6 项、每项 45ms 的错峰入场；`useReflow` 让删除/筛选后的列表平滑归位；`useTransient` 负责 toast 与二次确认。
- 每个动画都接 `useReducedMotion()`：降级后只保留解释状态变化的透明度变化，位移、缩放与回弹全部去掉。


## 隐私

- 首次启动展示隐私政策与用户协议；点击「同意并继续」前不初始化计时引擎、不申请权限、不写入业务数据。
- 不收集、不上传姓名、手机号、邮箱、身份证号、位置、通讯录、相机、麦克风、相册、剪贴板或设备标识符。
- 任务、时间块、专注记录与设置只保存在设备本地；没有云端备份、账号体系或远程推送。
- 「复盘 → 清空所有数据」可删除全部业务数据；「关于时舟 → 撤回隐私同意」可回到同意页。
- 应用内提供隐私政策、用户协议、个人信息收集清单与第三方 SDK 清单。

## 已知限制

- 只有本地存储，没有多设备同步。
- 通知为本地通知；Android 12+ 未申请精确闹钟权限，系统可能把提醒延后几分钟。
- 设备重启后，尚未触发的本地提醒不会自动恢复。
- 「息屏显示」是 App 内的纯黑常亮屏，只在 App 位于前台时生效，无法绘制系统级 AOD。
- Web 端仅用于开发预览；磨玻璃与动效手感需在 release 包和量产机上验证。
